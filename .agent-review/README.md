# Agent Review Artifacts

This folder is for review evidence produced by local agent runs.

It is not a design source of truth. Use current product code, current docs, or a
fresh screenshot from the branch when reviewing UI.

Rules:

- Put sanitized screenshots or GIFs in `visuals/` when a PR changes UI, app
  copy, or user-facing flow.
- Do not include private transcripts, customer data, tokens, personal paths, or
  real user content.
- Prefer small PNGs. Use GIFs only when motion matters.
- Old visuals are evidence for their original PR only.
