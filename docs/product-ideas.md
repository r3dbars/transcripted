# Transcripted Product Ideas

This is the loose inbox for product ideas.

Capture first. Sort later. Do not treat these as committed roadmap items until
they are checked against the live app, user risk, and current release state.

## Inbox

- [ ] Granola-style install polish: make Transcripted setup feel obvious before
  the app even opens. The bar is a clean DMG window, clear drag-to-Applications
  moment, simple first-run handoff, and no confusion about what happens next.
- [ ] Plain-language permissions screen: explain setup as "transcribe my
  voice" and "transcribe other people's voices" instead of leading with macOS
  permission names. Show what is already enabled, make the blocked next step
  obvious, and keep the copy calm about local capture and no meeting bots.
- [ ] Pre-explain system-audio permission before macOS asks: the in-app copy
  should match the system prompt closely enough that "Allow" feels expected,
  not surprising. Spell out that this is for meeting/system audio output and
  keep the no-bot/local trust message visible before the native dialog appears.
