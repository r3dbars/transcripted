# App icon

The app icon is the outlined speech bubble with a hidden "T" (round 8 of the icon mockups, no
accent color):

- `round8/H-mono-light.svg`: graphite bubble on an off-white tile. The light app icon.
- `round8/H-mono-dark.svg`: white bubble on a graphite tile. The dark app icon.

The shipped icon lives in `AppIcon/Transcripted.icon/` and `Resources/Transcripted.icns`. The menu
bar glyph (`Sources/UI/MenuBar/MenuBarGlyph.swift`, `docs/assets/menu-bar-icon/`) uses the same
geometry.

`website/` holds the matching logo files and site mockups.

The earlier rounds (other shapes, colors and accents) and their generator scripts were removed on
2026-09-25. They are still in git history.
