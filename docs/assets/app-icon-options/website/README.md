# Website assets

- `simple-site.html`: a one-screen version of transcripted.app. Logo, one headline, one line, a
  Download button and three short points. This is the latest ask ("super simple").
- `site-mockup.html`: the longer version of the site (how it works, sample file, privacy, features).
- `logo-light.svg` / `logo-dark.svg`: the chosen icon (round 8, no accent) as vectors.
- `logo-*.png` (64 px) and `icon-*.png` (512 px): rendered copies the mockups reference. The pages
  show the light icon in light mode and the dark icon in dark mode.

Colors are the app's own neutrals from `Sources/UI/Shared/LibraryTokens.swift`, with no accent:
page `#F7F7F5`, ink `#1D1D1F`; dark page `#1A1A1B`/`#232325`, dark ink `#F5F5F3`.
