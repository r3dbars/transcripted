Product Hunt, X/Twitter, Reddit, launch directories, and founder updates.

## Safety Notes

All captured media uses synthetic demo meetings and dictations. Do not replace
these assets with screenshots that show private transcripts, customer data,
real meeting titles, emails, tokens, or personal file paths.
